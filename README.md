# Приложение поворота картинки
Переходя на веб-приложение по ссылке http://127.0.0.1:8000/, пользователю открывается страничка 
загрузки png изображения через Проводник, угол поворота картинки и при выборе всех компонентов нужно подтвердить обработку через reCaptcha. 
При подтверждении капчи нажимаем на обработку и на странице с ссылкой http://127.0.0.1:8000/process отображается оригинальная и повернутая картинка на заданный угол и гистограммы распределения их цвета

## main.py
В этом файле расписана логика обработки изображения, а также создание ссылок через FastAPI.
@app.get("/") возвращает шаблон страницы на html и css.

@app.post("/process") возвращает обработаное изображение, гистограммы и выводит их на странице.

## HTML Файлы
### index.html
В голове html файла название вкладки (" Загрузка изображения"), ссылка на recaptcha и подключения файла по стилизации через css файл.
В теле файла создается контейнер ву котором хранится основной интерфейс страницы и окошко recaptcha
